# Poster Assets

This folder contains poster-friendly section files with more visuals and less text.

Files:

- `problem_statement.svg`
- `abstract.svg`
- `working_prototype.svg`
- `methodology_technical_stack.svg`
- `result.svg`
- `conclusion.svg`
- `team.md`

Usage:

- Import the SVG files directly into your poster layout.
- Use `team.md` as a quick fill-in template for the team box.
- If a box is narrow, scale the SVG proportionally instead of editing the poster text first.
